# IPT10 Database Programming Laboratory

This project demonstrates database-driven web applications using PHP and MySQL.

## Implementations

### MySQLi
The `ipt10 lab` folder contains the MySQLi implementation with:
- Create
- Read/View
- Update/Edit
- Delete
- Input validation
- Prepared statements

### PDO
The `ipt10 lab pdo` folder contains the PDO implementation with:
- Create
- Read/View
- Update/Edit
- Delete
- Input validation
- Prepared statements

## Database

Database name:

`ip10_lab`

Main table:

`students`

## Environment

- PHP
- MySQL
- XAMPP
- Apache
- phpMyAdmin
